# DinamicaGreedyRabs
Resolucion de el trabajo practico de Dinamica y Greedy para la materia "Algoritmos y estructuras de datos avanzados" de 6to INFO Instituto Politecnico Superior a cargo del profesor Juan Manuel Rabasedas.

## Dinamica
La funcion R tiene un costo de O(3^n) // Funciona con un "Divide y venceras", es top-bottom.

La funcion R_iter tiene un costo de O(n^2) // Funciona partiendo desde la subestructura mínima, es bottom-up.
